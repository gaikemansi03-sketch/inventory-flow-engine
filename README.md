# Inventory Flow Engine

A lightweight workflow-driven application for managing inventory operations, routing flows, and coordinating the movement of stock through a business process.

## Overview

This repository contains the code for an inventory flow engine that can be extended to support:

- inventory intake and validation
- state transitions across operational stages
- workflow orchestration for stock movement
- reporting and monitoring of inventory events
- integration with UI and backend services

## Tech Stack

The project includes a mix of frontend and backend tooling, with the majority of the codebase built in JavaScript and Python.

- JavaScript
- Python
- CSS
- HTML
